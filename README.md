# Kero

A native terminal workspace for macOS.

![preview](https://kero.sh/kero-screenshot.png)

## Features

- Swift + libghostty
- Native design
- Split panes
- Git intergration
- Group by projects
- File tree

## Download

https://kero.sh

Or install via Homebrew:

```sh
brew install grikomsn/kero/kero
```
